# RocketLight – veröffentlichter Pitch

[Der vollständige Pitch auf GitHub Pages](https://pogoner.github.io/InnovationManagement/pitch/) verbindet die sieben Schritte auf einer Seite. Die [Inhaltsdokumentation](../../pitch/CONTENT.md) erklärt Quellen, Zuordnungen, Korrekturen und Modellgrenzen.

Die Aufnahme entstand am 14.11.2026 in Chromium an der veröffentlichten Seite, bei einem gemessenen Browser-Viewport von 1363 × 936 CSS-Pixeln. Das Hintergrundmotiv ist die bestehende Konzeptvisualisierung aus `teil6/`.
